## 🇬🇧 English Overview

### 💡 About The Project
**AI Screen-to-Code Studio** is a modern desktop utility designed for developers, UI/UX designers, and product creators. It bridges the gap between visual design and front-end code by utilizing Google Gemini's multimodal vision capabilities. Simply drag and drop any UI screenshot, wireframe, or mockup, and receive production-ready front-end code within seconds.

### ✨ Key Features
- **Drag-and-Drop Workflow:** Easily drop image files (`.png`, `.jpg`, `.jpeg`, `.webp`) into the application.
- **Production-Ready Code:** Generates clean HTML combined with Tailwind CSS CDN and modern responsive layouts (Flexbox/Grid).
- **Live In-Browser Preview:** Open and inspect the generated layout directly in your default browser with a single click.
- **Iterative AI Refinement:** Request incremental adjustments (e.g., "Change the navbar color to navy", "Make buttons rounded") without starting from scratch.
- **Offline/Restricted Network Guard:** Built-in intelligent diagnostic alerts for connection dropouts and proxy requirements.
- **Privacy First:** User API keys are stored locally on the client machine and never exposed.

### 🛠️ Quick Start Guide
1. Download and extract the `.zip` archive.
2. Launch `AI_Screen_to_Code.exe`.
3. Get a free Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
4. Paste your API key into the top input field.
5. Drag your UI screenshot into the workspace and click **Generate Code ✨**.

## 🇮🇷 راهنمای فارسی / Persian Overview

### 💡 درباره پروژه
نرم‌افزار **AI Screen-to-Code Studio** یک ابزار دسکتاپ مدرن و کاربردی برای برنامه‌نویسان، طراحان رابط کاربری و مدیران محصول است. این برنامه با اتکا به مدل‌های بینایی ماشین چندوجهی گوگل جمینای، تصاویر رابط کاربری، اسکچ‌ها یا اسکرین‌شات‌ها را در چند ثانیه به کدهای استاندارد و ریسپانسیو فرانت‌اند تبدیل می‌کند.

### ✨ امکانات و قابلیت‌های کلیدی
- **پشتیبانی از درگ‌وان‌دراپ:** امکان کشیدن و رها کردن ساده انواع فایل‌های تصویری به داخل محیط نرم‌افزار.
- **تولید کدهای استاندارد:** ساخت خروجی‌های ساختاریافته بر پایه HTML و فریم‌ورک Tailwind CSS به همراه آیکون‌ها و فونت‌های CDN.
- **پیش‌نمایش زنده در مرورگر:** امکان مشاهده و تست آنی وب‌پیج تولیدشده در مرورگر تنها با یک کلیک.
- **اعمال تغییرات هوشمند (Iterative Refinement):** قابلیت چت و اعمال تغییرات سفارشی روی کد (مثلاً «دکمه‌ها را گردتر کن» یا «رنگ هدر را تیره کن»).
- **سیستم مدیریت خطای شبکه:** هشدارهای واضح فارسی/انگلیسی در صورت قطع بودن اینترنت یا لزوم فعال‌سازی فیلترشکن.
- **امنیت کامل داده‌ها:** کلید اختصاصی API هر کاربر تنها بر روی سیستم شخصی خودش ذخیره شده و هیچ‌گونه دیتایی به اشتراک گذاشته نمی‌شود.

### 📌 نکات مهم برای کاربران داخل ایران
- سرویس‌های هوش مصنوعی گوگل برای آی‌پی‌های ایران محدود هستند؛ بنابراین قبل از زدن دکمه تبدیل کد، **فیلترشکن سیستم خود را فعال و به صورت کامل تانل (System-wide / TUN Mode)** نمایید.
- کلید رایگان API خود را می‌توانید مستقیماً از پنل [Google AI Studio](https://aistudio.google.com/app/apikey) دریافت کرده و در برنامه وارد کنید.
